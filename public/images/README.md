## Tips

- Use JPG format for photos (smaller file size than PNG)
- Compress images before adding them — recommended tool: https://squoosh.app (free, no upload limit)
- Aim for under 300KB per image for fast loading
- Free photos: https://unsplash.com — search the terms above, download "Regular" size

## How it works

Each image renders behind a dark overlay so text stays readable regardless of the photo.
You don't need to edit any code — just drop the files here with the exact filenames above.
