# novanest-website-web

NovaNest Public Website — React + Vite + Tailwind CSS

## Overview

Public-facing website and customer portal for the NovaNest real estate platform.

## Features

### Public Website
- Home page with featured projects and available apartments
- Properties listing with search and filter (location, type, bedrooms, price, availability)
- Project detail pages (gallery, facilities, floor plans, availability)
- Apartment detail pages with inquiry form
- About Us page
- Careers page with job listings and application form
- News & Insights articles
- Contact page with inquiry form

### Customer Portal
- Secure customer login (admin-created accounts only)
- My Apartment — full unit details, project info, facilities, gallery
- Apartment Updates — chronological update timeline
- Documents — files shared by the company
- Notifications — unread alerts
- Profile — update phone and change password

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- TanStack Query
- React Router v6
- React Hook Form
- Axios
- Lucide React

## Getting Started

```bash
npm install
npm run dev       # runs on http://localhost:3000
```

## Requirements

The NovaNest backend must be running on port 5000.
See: https://github.com/dulajweligaththa08/novanest-backend-web
